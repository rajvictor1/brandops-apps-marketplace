# BrandOps Apps Marketplace

A calm, product-first marketplace for BrandOps AI tools.

## Products listed

- **LinkedIn Carousel Generator** — 5-slide visual stories from a research topic
- **AI Newsletter Generator** — cited newsletter drafts with lead visuals
- **LinkedIn Automation Studio** — full review-first content workspace
- **GEO / SEO Audit Toolkit** — score your site for AI search + traditional SEO

## Tech stack

- Next.js 15 (static export)
- React 19
- TypeScript
- Tailwind CSS 3
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output is written to `dist/`.
